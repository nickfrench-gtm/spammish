# Brand provenance

The owner selected the electric-blue mail-vortex reference on October 2, 2026. `spammish-banner.jpg` is a mechanically resized/compressed copy of that supplied image, including its original lettering. Marketing uses the right-hand artwork with CSS object positioning alongside accessible HTML product copy.

The canonical black-background vortex icon is the owner-supplied square Abyss image. `desktop/assets/icon.png`, `abyss-mark.png`, desktop header image and 16–256px variants are mechanical size derivatives of that source, without a redesigned transparent mark. The monochrome menu-bar spiral is geometric utility artwork. Historical shield/transparent variants do not define the current identity.

`social.png` is a deterministic HTML composition using the supplied mail-vortex reference and truthful copy. No private mail or measured performance is shown.

Display font: Manrope variable, google/fonts ofl/manrope, SIL Open Font License; self-hosted with FONT-LICENSE.txt.
