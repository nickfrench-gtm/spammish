# Brand provenance

The canonical Abyss identity is based on the vortex image supplied by the owner on October 2, 2026: black center, electric-blue accretion ring, dark surround. `abyss-hero.jpg` is a mechanically resized/compressed derivative of that source.

`abyss-mark.png` is a built-in image-generation derivative of the same supplied image: preserve the black center and blue asymmetric ring, simplify to broad luminous ribbons, remove stars/debris and outer tile, transparent exterior. It is not an unrelated mark. The 16/32/64/128/256px variants, desktop header PNG and 1024px app icon are mechanical size derivatives. `desktop/assets/abyss.icns` contains native macOS icon sizes. The menu-bar template is an authored monochrome three-arm spiral geometry preserving the void/ring concept.

`social.png` is a deterministic HTML composition of the mark and truthful product copy, captured at 1200×630. No mailbox imagery, metrics or testimonial data is used.

The previous shield is retired from current surfaces. Historical source archives/screenshots are not rewritten cosmetically.
