# Spammish 0.4.4

Make unwanted email disappear. Open source, MIT, local-first.

This update adds optional usage milestones so we can learn whether installations launch, connect Gmail, make a first automatic Abyss move, continue running after 7/30 days, or perform a Rescue.

Sharing is off until you choose it. Choose **No thanks** to keep using Spammish without sharing, or turn it off later under **Usage privacy**. Only a random installation ID, milestone name, app version and platform are sent. No email content, account information, message IDs, classifier evidence or credentials are included. No analytics SDK or AI API is required. Network failure never stops Gmail processing.

These metrics count participating installations, not verified people, classification accuracy or every email moved. Records expire within 90 days including the configured backup window. See [privacy and controls](../../PRIVACY.md#optional-desktop-usage-milestones).

Filtering defaults and Gmail/Abyss/Rescue behavior are unchanged. Installation remains builder-oriented: local unsigned macOS source build and user-configured Google OAuth. Follow the [desktop installation guide](../desktop-install.md). Report issues with sanitized details only; never post private emails, tokens or credentials.
