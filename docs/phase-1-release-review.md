# Source release review: 0.4.0

Spammish is published as MIT source: **Make unwanted email disappear.** The primary path is agent-assisted or manual local browser installation with the user's own Google OAuth client. Desktop source remains optional. No public production installer or managed OAuth flow is claimed.

The shared account/worker engine, provider reads and label mutations, deterministic score, relationship protections, narrow corrections and local storage were reviewed against README, PRIVACY.md and SECURITY.md. The 27-case controlled Gmail record is in [acceptance-0.4.0.md](acceptance-0.4.0.md), including protected legitimate categories, unread preservation, Abyss/Rescue, state recovery and disclosed injected boundaries. This does not establish statistical accuracy.

The current public audit also reconciles PRODUCT.md, installation/doctor terminology, contribution/bug-report guidance, source metadata and concise release notes. Final verification details and reviewed source commit are recorded in the GitHub release. The original v0.4.0 tag remains intact; source follow-ups are identified explicitly rather than silently replacing a published tag.

Gmail scope permits more than implemented label operations. Desktop credentials use OS encryption while metadata relies on OS/disk protection; the local browser state uses a private AES-GCM vault key. Bodies are transient, not retained or sent to a maintainer/AI provider. Disconnect clears active account state but backups may retain prior data. See the policies for the full data inventory.

Nonblocking limitations: own Google registration/consent and applicable testing limits, awake/online worker, Gmail delivery before polling, quota delays, no signed/notarized consumer installer and no representative labeled accuracy benchmark. No Chrome extension or hosted Cloud service is included.
