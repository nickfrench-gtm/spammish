# Security policy

Do not include message contents, credentials, OAuth tokens, or personal data in public issues.

For a suspected vulnerability, contact the maintainers privately through the GitHub profile or repository security advisories. Include a concise description and steps to reproduce. Allow time for a fix before public disclosure.

Self-hosters are responsible for restricting access to the service, protecting its database and token-vault key, and using HTTPS for remote access. Revoke Spammish's Google access from your Google Account if you stop using it.
