How it works

Connecting Gmail starts a check of its existing inbox, then watches new mail while your Mac is awake and online. Each Gmail account has its own pause control and The Abyss label. Close this window to keep it running in the menu bar; Quit stops processing. It inspects message text locally without changing unread state, then moves only high-confidence matches to Gmail’s recoverable The Abyss label.

It never sends, replies, deletes, clicks email links, or unsubscribes. Gmail may show a message briefly before the next check.
