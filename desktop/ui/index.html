How it works

When first enabled, Spammish checks your existing inbox, then watches new mail while your Mac is awake. It inspects message text locally without changing unread state, then moves only high-confidence matches to Gmail’s recoverable The Abyss label.

It never sends, replies, deletes, clicks email links, or unsubscribes. Gmail may show a message briefly before the next check.
